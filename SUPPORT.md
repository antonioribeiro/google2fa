# Support

- **Version support & lifecycle policy**: see the [Version Support](README.md#version-support) section in the README.
- **Questions / usage help**: open a [discussion](https://github.com/antonioribeiro/google2fa/discussions).
- **Bug reports**: open an [issue](https://github.com/antonioribeiro/google2fa/issues) with a minimal reproduction (PHP version, OS, code snippet, expected vs actual behavior).
- **Security vulnerabilities**: see [SECURITY.md](SECURITY.md) — do **not** open a public issue.
